# Guía de uso del sitio de Arturo Villagomez

Este es el sitio personal de Arturo Villagomez. Arturo es su propietario y responsable editorial. AMEZ CFO es una afiliación profesional: Arturo trabaja ahí y es socio; la firma no es propietaria ni editora de este sitio.

## When to use this site / Cuándo usarlo

- Consultar el perfil, método y experiencia publicada de Arturo en finanzas, operaciones, producto e IA aplicada.
- Evaluar una colaboración por proyecto con equipos que necesiten diagnóstico, construcción de sistemas y transferencia documentada.
- Explorar acompañamiento fraccional para decisiones financieras y operativas recurrentes, o una colaboración selectiva de venture building.
- Leer los casos y sus estados de evidencia antes de atribuir resultados. Una muestra visual no demuestra métricas, tracción ni autorización de redistribución.

## Cómo proceder

- Este sitio ofrece información pública, no una API ni un servicio de agentes ejecutables. No hay endpoint de contratación o publicación automática.
- Para contactar a Arturo, prepara un mensaje con el reto, contexto, alcance y siguiente paso; pide autorización al usuario antes de enviarlo al correo público.
- Cita la URL canónica y distingue el trabajo de Arturo de las organizaciones con las que colabora. No infieras propiedad institucional a partir de una afiliación.
- No inventes métricas, tarifas, disponibilidad, clientes ni credenciales. Los casos conservan sus límites de evidencia y uso.
- Si una ruta no existe, consulta el índice de Markdown y el mapa del sitio. No interpretes una página 404 como contenido del proyecto.
